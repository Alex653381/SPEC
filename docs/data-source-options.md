# 数据源替代方案调研

生成时间：2026-10-31。本调研只做离线比对，不调用真实接口，不实现 fetcher，不修改数据库或采集流程。

## 1. 评价维度

- 技术可用性：能否获取所需数据、是否支持日期范围或安全限量返回。
- 数据质量：字段口径、单位、复权、历史覆盖和稳定性是否有可靠依据。
- 使用许可：当前证据是否足以支持预期用途。免费、开源、可访问或个人本地运行不视为已获授权。

## 3. 四类资产推荐方案

### 股票

- 首选：新浪 `stock_zh_a_daily(qfq)`。已有完整实测，支持日期范围，无重复/负价。
- 备选：腾讯 `stock_zh_a_hist_tx` 只建议用于近期增量且需过滤负价和周末行；东方财富 `stock_zh_a_hist` 受限流影响。

### 指数

- 首选：腾讯 `stock_zh_index_daily_tx`，用于日期范围内的增量获取；明确 `amount` 实为成交量（手），不保存成交额。
- 备选：新浪 `stock_zh_index_daily` 用于一次性全量初始化（需确认许可），东方财富 `index_zh_a_hist` 仅在许可与限流问题解决后用于成交额。

### ETF

- 首选：东方财富 `fund_etf_hist_em`，支持日期范围，作为增量接口候选。
- 备选：新浪 `fund_etf_hist_sina` 用于全量初始化（需确认许可）。

### 场外基金

- 首选：自研基于天天基金 `lsjz` 端点的区间 fetcher，支持 `startDate/endDate/pageSize`；AKShare 当前没有通用开放式基金区间封装。
- 备选：`fund_open_fund_info_em` 全量返回后用客户端切片，仅作为低频率回退。

## 4. 证据来源

- 接口签名：本地 AKShare 1.20.18 离线 `inspect.signature` 枚举。
- 基金 `lsjz` 端点参数：AKShare 源码 `akshare/fund/fund_em.py` 中 `startDate/endDate/pageSize` 使用记录。
- 新浪与东方财富条款：见 `docs/data-source-audit.md` 第 7 节。
- 腾讯自选股协议：搜索结果显示“个人、不可转让、非商业”使用许可。
- 中证指数/中证商品指数：官方声明，对外发布指数行情需书面授权。

## 5. 未确认事项

- 东方财富 `index_zh_a_hist`、`fund_etf_hist_em` 的精确字段和单位。
- 腾讯 `stock_zh_index_daily_tx` 的历史覆盖和 `amount` 是否在全部代码上均为成交量。
- 天天基金 `lsjz` 通用开放式基金的返回字段、分页上限和限流规则。
- 中证指数官方接口对沪深300的可用性及数据字段。
- 所有候选数据源面向“本人及一两位同学”使用时的授权边界。

## 6. 后续验证计划

1. 许可确认后，先对四个首选接口各做一次最小范围真实验证，记录字段与单位。
2. 对 `lsjz` 端点先做单页 Mock/离线结构验证，再在许可确认后做单次小范围真实请求。
3. 验证东方财富候选是否仍受本地限流影响，以及腾讯指数字段是否稳定。
