# 真实接口小规模验证

生成时间：2026-10-31

## 1. 结论

本轮未执行任何真实网络请求。原因：

1. 数据使用许可仍未确认，不能把接口可访问视为已获展示/抓取授权。
2. 指数、ETF、场外基金所选接口不支持日期范围，真实请求会返回全量历史，超出本轮“最近约 20 个自然日、不下载全量历史”的限制。

本轮交付受控验证脚本和离线 Mock 测试，真实请求待许可确认后由脚本显式执行。

## 3. 字段语义核对状态

已由 `docs/data-source-audit.md` 实测确认：

- 股票：`volume` 为股、`amount` 为元，前复权 `qfq`，最新日与不复权一致。
- 指数：`volume` 为股，无成交额。
- ETF：`volume` 为股、`amount` 为元。
- 基金：单位净值与累计净值按业务日期返回，需区分净值日期与抓取时间。

仍不确定：

- 指数成交额来源未验证。
- 基金周末占位行的最终业务规则，需可靠交易日历。

## 4. 脚本行为

`scripts/validate_live_adapters.py`：

- 默认不联网，需显式 `--live` 才可能请求。
- 每类接口最多请求一次，不重试、不并发、不批量。
- 非区间接口直接阻止并记录原因。
- 股票接口设置 20 秒 socket 超时。
- 默认只打印摘要；`--save` 才把脱敏摘要写入 `data/samples/`。
- 不写正式 SQLite，不调用采集入库服务，不输出 Cookie/令牌等敏感信息。

## 5. 待解决问题

- 数据许可确认后，股票可执行最近 20 天窗口的真实验证。
- 指数、ETF、基金需先找到支持日期范围或可安全限量返回的接口，否则保持阻止。
