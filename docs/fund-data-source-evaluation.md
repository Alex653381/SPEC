# 场外基金净值候选数据源评估

生成时间：2026-10-31。本阶段不执行真实网络请求，不写入业务数据库。

## 1. 候选方案

### 候选 A：天天基金 / 东方财富

- AKShare 入口：`fund_open_fund_info_em`、`fund_open_fund_daily_em`。
- 字段：单位净值、累计净值、净值日期；快照接口另有申购/赎回状态。
- 日期范围：`fund_open_fund_info_em` 返回全量，不支持服务端日期区间；底层 `lsjz` 端点支持 `startDate/endDate/pageSize`。
- 历史覆盖：现有报告实测 `110022` 自 2010-08-20，`000001` 自 2001-12-18。
- 更新频率：净值按基金公布节奏，通常交易日次日披露，存在季度末周末占位行。
- 许可：东方财富条款限制行情复制与提供；个人研究边界未确认。
- 免费额度：公开网页接口，无明确额度；AKShare 声明仅学术研究。
- 维护风险：网页端点可能变动；本地稳定，香港服务器曾出现间歇空表。

### 候选 B：新浪基金

- 提供基金净值页面与快照，但 AKShare 对场外基金净值历史的封装主要走东方财富，新浪渠道字段和稳定性证据不足。
- 字段与日期范围能力待实测。
- 许可：新浪协议限个人、非商业；对外展示未确认。
- 技术可行性：当前证据不足以作为首选，待验证。
